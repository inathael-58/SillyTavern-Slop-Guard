# Slop Guard — SillyTavern extension

แบนคำหรือวลีที่โมเดลชอบใช้ซ้ำ เช่น Gemini ชอบ "อย่างถือสิทธิ์" ส่วน DeepSeek ชอบ "หัวเราะแห้งแล้ง" **ใช้ได้กับทุก preset** เพราะไม่ต้องพึ่ง placeholder ใน preset และแยกกฎตามโมเดลได้

แต่ละกฎทำงาน 2 ทาง:

1. **กฎใน prompt:** แทรกคำสั่งไว้ที่ depth ที่ตั้งไว้ใน chat history โดยใส่**เฉพาะกฎของโมเดลที่ใช้อยู่** Gemini จะไม่เห็นคำติดของ DeepSeek จึงไม่ไปกระตุ้นให้มันใช้คำนั้นตาม
2. **ลบในข้อความ:** พอบอทตอบเสร็จ ถ้าเจอคำที่แบน จะมี popup ให้ดูก่อนว่าจะลบหรือแทนที่ตรงไหน แล้วแก้ในข้อความที่บันทึกไว้จริง คำนั้นจะไม่ค้างอยู่ใน history ที่ส่งกลับไปให้โมเดลอ่าน

## ติดตั้ง

Extensions → Install extension → วาง URL ของ repo นี้

## ใช้งาน

ไปที่ Extensions → **Slop Guard** มีกฎตัวอย่างของ Gemini กับ DeepSeek ใส่ไว้ให้แล้ว

### กฎหนึ่งข้อ

| ช่อง | ความหมาย |
|---|---|
| ☑ (ซ้ายสุด) | เปิด/ปิดกฎ |
| หา | วลีตรงๆ เช่น `possessively` หรือ regex แบบ `/(หัวเราะ)แห้งแล้ง/` |
| ลบในข้อความ | ติ๊ก = ลบหรือแทนที่ในข้อความที่บอทตอบ ไม่ติ๊ก = ใช้เป็นกฎใน prompt อย่างเดียว |
| แทนด้วย | เว้นว่าง = ลบทิ้ง ใช้ `$1` อ้างกลุ่มใน regex ได้ |
| โมเดล | ชื่อบางส่วนของโมเดล คั่นด้วยจุลภาค เช่น `gemini, deepseek` เว้นว่าง = ทุกโมเดล |
| กฎใน prompt | คำสั่งที่จะแทรกให้โมเดล เว้นว่าง = ไม่แทรก |

- ช่อง **โมเดล** มีผลเฉพาะกับกฎใน prompt ส่วนการลบในข้อความใช้กับทุกโมเดล เพราะถ้าโมเดลไหนไม่ได้เขียนคำนั้นออกมา กฎก็แค่ไม่ทำงาน ไม่มีผลเสีย
- ถ้า "หา" เป็นวลีธรรมดาและ "แทนด้วย" ว่าง ระบบจะลบช่องว่างหน้าวลีไปด้วย เช่น `held her possessively close` จะเหลือ `held her close`
- ถ้าเขียน regex ผิด ช่อง "หา" จะขึ้นกรอบแดง

### เมื่อเจอคำแบนในข้อความใหม่

- **ถามก่อนลบ:** popup จะแสดงจุดที่เจอ <del>ส่วนที่จะหาย</del> และ <ins>ส่วนที่ใส่แทน</ins> ให้เลือกได้ว่าจะใช้กฎไหน มีปุ่ม **ลบอัตโนมัติต่อจากนี้** ถ้าไม่อยากให้ถามอีก
- **ลบอัตโนมัติ:** ลบให้ทันที แล้วแจ้งเป็น toast
- **ไม่ลบ:** ใช้แค่กฎใน prompt

### ปุ่มต่างๆ

- **สแกนแชทด้วย AI** (`/slopscan`): ให้โมเดลที่ใช้อยู่อ่านข้อความล่าสุดของบอท แล้วหาวลีที่ซ้ำ ระบบนับเองว่าวลีนั้นเจอในแชทจริงอย่างน้อย 2 ครั้ง และยังไม่มีกฎไหนครอบไว้ จากนั้นแสดงให้แก้และเลือกก่อนเพิ่มเป็นกฎ โดยตั้งช่องโมเดลเป็นตระกูลของโมเดลที่ใช้อยู่ให้ ถ้าติ๊ก **เฉพาะที่โมเดลเดียวกันเขียน** จะสแกนแค่ข้อความที่โมเดลตระกูลเดียวกันเขียน (ต้องมีอย่างน้อย 5 ข้อความ)
- **ล้างทั้งแชท** (`/slopclean`): หาคำแบนในทุกข้อความของบอทในแชทที่เปิดอยู่ แล้วให้เลือกลบ ใช้กับแชทเก่าที่คำติดสะสมไว้แล้ว
- **นำเข้า / ส่งออก:** เก็บรายการกฎเป็นไฟล์ JSON

### ตั้งค่า

| ตัวเลือก | ค่าเริ่มต้น | ทำอะไร |
|---|---|---|
| ใส่กฎลงใน prompt | เปิด | ปิดแล้วจะเหลือแค่การลบในข้อความ |
| depth | 1 | ตำแหน่งที่แทรกนับจากท้ายแชท 0 = ท้ายสุด ถ้าคำยังหลุดบ่อยให้ลด |
| role | System | role ของข้อความที่แทรก |

บรรทัด **โมเดลตอนนี้** บอกชื่อโมเดลที่ extension เห็นอยู่ และจำนวนกฎใน prompt ที่ใช้กับโมเดลนั้น ใช้เช็คได้ว่าช่องโมเดลของแต่ละกฎตรงกับชื่อจริงหรือเปล่า

## เขียนกฎใน prompt ยังไงให้ได้ผล

- **บอกสิ่งที่ให้ทำแทน** เช่น "ถ้าจะสื่อความหวง ให้แสดงผ่านการกระทำ" ได้ผลกว่าการห้ามอย่างเดียว
- **ยกคำที่ห้ามแค่ครั้งเดียว** ถ้ายกหลายครั้งหรือเป็นรายการยาว จะยิ่งกระตุ้นให้โมเดลใช้คำนั้น
- **ผูกกับโมเดลที่ติดคำนั้นจริงๆ** อย่าปล่อยช่องโมเดลว่าง ถ้าเป็นคำที่ติดอยู่โมเดลเดียว
