# Slop Guard — SillyTavern extension

แบนคำหรือวลีที่โมเดลชอบใช้ซ้ำ เช่น Gemini ชอบ "อย่างถือสิทธิ์" ส่วน DeepSeek ชอบ "หัวเราะแห้งแล้ง" **ใช้ได้กับทุก preset** เพราะไม่ต้องพึ่ง placeholder ใน preset และแยกกฎตามโมเดลได้

แต่ละกฎเลือกได้ว่าจะจัดการคำนั้นแบบไหน:

| แบบ | ใช้กับ | ทำอะไร |
|---|---|---|
| **แก้คำผิด** | คำผิดหรือคำแปลกที่ไม่ควรโผล่เลย เช่น "เงินยวบยาบ" "หัวเราะแห้งแล้ง" | ลบหรือแทนที่ทุกครั้งที่เจอ |
| **หลากคำ** | คำที่ใช้ได้แต่ใช้ซ้ำจนน่าเบื่อ เช่น "อย่างสมบูรณ์แบบ" "อย่างถือสิทธิ์" | ปล่อยผ่านครั้งแรกแล้วติดคูลดาวน์ ระหว่างนั้นสุ่มคำความหมายเดียวกันจากคลังมาแทน มี AI ช่วยคิดคำ |
| **แค่ prompt** | สิ่งที่แก้ด้วยการแทนคำไม่ได้ | ไม่แก้ข้อความ บอกโมเดลผ่านกฎใน prompt อย่างเดียว |

การแก้ข้อความจะแก้ในข้อความที่บันทึกไว้จริง คำนั้นจะไม่ค้างอยู่ใน history ที่ส่งกลับไปให้โมเดลอ่าน

ทุกกฎใส่ **กฎใน prompt** เพิ่มได้ด้วย ระบบจะแทรกไว้ที่ depth ที่ตั้งไว้ โดยใส่**เฉพาะกฎของโมเดลที่ใช้อยู่** Gemini จะไม่เห็นคำติดของ DeepSeek จึงไม่ไปกระตุ้นให้มันใช้คำนั้นตาม

## ติดตั้ง

Extensions → Install extension → วาง URL ของ repo นี้

### อัปเดต

Extensions → Manage extensions → อัปเดต Slop Guard แล้วกด **โหลดเวอร์ชันล่าสุด** ในแผง Extensions → Slop Guard

เบราว์เซอร์ (โดยเฉพาะ ST ที่เปิดจากไอคอนบนหน้าโฮมของ iPhone) มักเก็บไฟล์เก่าไว้ แม้อัปเดตแล้วก็ยังรันตัวเดิม ปุ่ม **โหลดเวอร์ชันล่าสุด** จะดึงไฟล์ทุกไฟล์ของ Slop Guard จากเซิร์ฟเวอร์ใหม่แล้วโหลดหน้าใหม่ให้

- **ดูเวอร์ชัน:** บรรทัด "ที่รันอยู่" บอกเวอร์ชันที่**รันอยู่จริง** ต่อท้ายด้วยเวอร์ชันที่ติดตั้งไว้บนเซิร์ฟเวอร์
- **ถ้าสองเลขไม่ตรงกัน** จะขึ้นแจ้งเตือนค้างไว้ แตะแจ้งเตือนนั้นเพื่อโหลดใหม่ได้เลย (เช็คตอนเปิด ST และตอนกลับมาที่แท็บ ไม่เกินทุก 10 นาที)
- **ครั้งแรกที่อัปเป็นเวอร์ชันที่มีระบบนี้** ตัวเก่ายังเตือนไม่เป็น ให้ปิดแล้วเปิด ST ใหม่ หรือล้างแคชเบราว์เซอร์เองหนึ่งครั้ง

## ใช้งาน

ไปที่ Extensions → **Slop Guard** คนที่เพิ่งติดตั้งจะมีกฎตัวอย่างใส่ไว้ให้แล้ว ทั้งแบบแก้คำผิดและแบบหลากคำ

### กฎหนึ่งข้อ

| ช่อง | มีในแบบ | ความหมาย |
|---|---|---|
| ☑ (ซ้ายสุด) | ทุกแบบ | เปิด/ปิดกฎ |
| หา | ทุกแบบ | วลีตรงๆ เช่น `possessively` หรือ regex แบบ `/(หัวเราะ)แห้งแล้ง/` |
| แก้คำผิด / หลากคำ / แค่ prompt | ทุกแบบ | เลือกวิธีจัดการ ช่องด้านล่างจะเปลี่ยนตามแบบที่เลือก |
| แทนด้วย | แก้คำผิด | เว้นว่าง = ลบทิ้ง ใช้ `$1` อ้างกลุ่มใน regex ได้ |
| คลังคำ | หลากคำ | คำความหมายเดียวกัน บรรทัดละคำ |
| ให้คำเดิมผ่านครั้งแรก | หลากคำ | ติ๊ก = คำเดิมผ่านได้หนึ่งครั้งแล้วติดคูลดาวน์ ไม่ติ๊ก = แทนด้วยคำในคลังทุกครั้ง |
| AI ช่วยคิดคำ | หลากคำ | ให้โมเดลที่ใช้อยู่เสนอคำความหมายเดียวกัน แล้วเลือกเองว่าจะเพิ่มคำไหนลงคลัง |
| โมเดล | ทุกแบบ | โมเดลที่จะได้กฎใน prompt ใส่ชื่อบางส่วนคั่นด้วยจุลภาค เช่น `gemini, deepseek` เว้นว่าง = ทุกโมเดล |
| กฎใน prompt | ทุกแบบ | คำสั่งที่จะแทรกให้โมเดล ไม่ใส่ก็ได้ ยกเว้นแบบแค่ prompt |

- ช่อง **โมเดล** มีผลเฉพาะกับกฎใน prompt ส่วนการแก้ข้อความใช้กับทุกโมเดล เพราะถ้าโมเดลไหนไม่ได้เขียนคำนั้นออกมา กฎก็แค่ไม่ทำงาน ไม่มีผลเสีย
- ถ้ากฎยังทำงานไม่ได้ เช่น หลากคำแต่คลังว่าง หรือแค่ prompt แต่ไม่ได้เขียนกฎ จะมีคำเตือนสีส้มใต้ปุ่มเลือกแบบ
- แบบแก้คำผิดที่ "หา" เป็นวลีธรรมดาและ "แทนด้วย" ว่าง จะลบช่องว่างข้างวลีไปด้วยหนึ่งช่อง เช่น `held her possessively close` จะเหลือ `held her close`
- ถ้าเขียน regex ผิด ช่อง "หา" จะขึ้นกรอบแดง

### อัปจากเวอร์ชันก่อน 1.2

กฎเดิมยังอยู่ครบ (ใน 1.1.0 รายการกฎไม่แสดงเพราะบั๊ก แต่กฎยังทำงานอยู่) ระบบเลือกแบบให้จากค่าเดิม: ติ๊ก "ลบในข้อความ" → แก้คำผิด, ไม่ติ๊ก → แค่ prompt, มีคลังคำ → หลากคำ ถ้าเคยตั้ง "ไม่ลบ" ไว้ทั้งระบบ ทุกกฎจะเป็นแค่ prompt กฎเรื่องความซ้ำซากอย่าง "อย่างถือสิทธิ์" ให้เปลี่ยนเป็น **หลากคำ** แล้วกด **AI ช่วยคิดคำ**

### หลากคำ (คลังคำ + คูลดาวน์)

ตัวอย่าง: กฎ `อย่างสมบูรณ์แบบ` มีคลังคำ `พอดิบพอดี` `อย่างเหมาะเจาะ` `ราวกับสร้างมาคู่กัน` `ราวกับเกิดมาเพื่อกันและกัน` (กฎนี้ใส่มาเป็นตัวอย่างให้แล้วสำหรับคนที่เพิ่งติดตั้ง)

1. บอทเขียน "เข้ากันอย่างสมบูรณ์แบบ" ครั้งแรก → ปล่อยผ่าน แล้วคำนี้ติดคูลดาวน์
2. เขียนซ้ำระหว่างคูลดาวน์ (จะในข้อความเดียวกันหรือข้อความถัดไปก็ได้) → สุ่มคำจากคลังที่ไม่ติดคูลดาวน์มาแทน เช่น "เข้ากันพอดิบพอดี" แล้วคำนั้นติดคูลดาวน์
3. ครั้งต่อไปจะสุ่มได้คำอื่นในคลัง

**สุ่มจริง ไม่วนตามลำดับ:** ถ้าเหลือคำที่พ้นคูลดาวน์ไม่ถึง 3 คำ (คลังเล็ก หรือคำนั้นโผล่บ่อย) คำที่ติดคูลดาวน์มานานแล้วจะได้ลุ้นด้วยในโอกาสที่น้อยกว่า ถ้าใช้คูลดาวน์แบบเข้มอย่างเดียว คลังเล็กจะเหลือตัวเลือกแค่คำเดียวทุกครั้ง แล้ววนเป็นลำดับเดิมจนคนอ่านจับได้ แต่ระบบจะไม่ใช้คำเดิมซ้ำในข้อความเดียวกัน และไม่ใช้คำจากข้อความก่อนหน้า ถ้ายังมีคำอื่นให้เลือก ถ้าคลังมีคำน้อยกว่า 2 เท่าของคูลดาวน์ กฎจะขึ้นคำเตือนให้เพิ่มคำ


- **คูลดาวน์** ตั้งได้ในหน้าตั้งค่า (ค่าเริ่มต้น 5 ข้อความของบอท) ระบบดูจากข้อความในแชทจริง ว่าคำนั้นอยู่ใน N ข้อความล่าสุดของบอทหรือเปล่า จึงนับถูกเสมอแม้จะ swipe แก้ หรือลบข้อความ และคำในคลังที่บอทเขียนเองก็นับเป็นใช้แล้วด้วย
- **regex ก็ใช้ได้** ใส่ `$1` ในคำของคลังได้ เช่น กฎ `/(หัวเราะ)แห้งแล้ง/` คลังคำ `$1เบาๆ` `$1ในลำคอ`
- คำในคลังต้องลงช่องเดียวกับคำเดิมได้ ถ้าคำเดิมเป็นคำขยาย คำในคลังก็ต้องเป็นคำขยาย
- **ล้างทั้งแชท** ก็หมุนคำให้ด้วย โดยไล่จากข้อความเก่าไปใหม่ คำจึงไม่ซ้ำกันในข้อความที่อยู่ใกล้กัน

**AI ช่วยคิดคำ:** กดปุ่ม <i>AI ช่วยคิดคำ</i> ที่กฎ ระบบจะส่งคำนั้นพร้อมประโยคจากแชทที่มีคำนั้นให้โมเดลที่ใช้อยู่ ขอคำความหมายเดียวกันที่ใส่แทนในประโยคได้ แล้วแสดงทีละคำพร้อมตัวอย่างประโยคเมื่อใช้คำนั้นแทน ให้ติ๊กและแก้ก่อนเพิ่มลงคลัง กดซ้ำได้เรื่อยๆ จะได้คำที่ยังไม่มีในคลัง (กฎแบบ regex ต้องเปิดแชทที่มีคำนั้นอยู่ เพื่อให้รู้ว่าคำจริงคืออะไร) ส่วน **สแกนแชทด้วย AI** จะเสนอคลังคำมาให้พร้อมกับวลีที่เจอด้วย

### ถามก่อนแก้

- **ติ๊ก "ถามก่อนแก้ข้อความของบอท":** popup จะแสดงจุดที่จะแก้ <del>ส่วนที่จะหาย</del> และ <ins>ส่วนที่ใส่แทน</ins> ให้เลือกได้ว่าจะใช้กฎไหน มีปุ่ม **แก้เลยต่อจากนี้ ไม่ต้องถาม**
- **ไม่ติ๊ก:** แก้ให้ทันที แล้วแจ้งเป็น toast
- ถ้าอยากให้บางกฎไม่แก้ข้อความเลย ให้ตั้งกฎนั้นเป็น **แค่ prompt**

### ปุ่มต่างๆ

- **สแกนแชทด้วย AI** (`/slopscan`): ให้โมเดลที่ใช้อยู่อ่านข้อความล่าสุดของบอท แล้วหาวลีที่ซ้ำ ระบบนับเองว่าวลีนั้นเจอในแชทจริงอย่างน้อย 2 ครั้ง และยังไม่มีกฎไหนครอบไว้ จากนั้นแสดงให้แก้ เลือกแบบของกฎ และเลือกก่อนเพิ่มเป็นกฎ พร้อมคลังคำที่ AI เสนอ โดยตั้งช่องโมเดลเป็นตระกูลของโมเดลที่ใช้อยู่ให้ ถ้าติ๊ก **เฉพาะที่โมเดลเดียวกันเขียน** จะสแกนแค่ข้อความที่โมเดลตระกูลเดียวกันเขียน (ต้องมีอย่างน้อย 5 ข้อความ)
- **ล้างทั้งแชท** (`/slopclean`): ใช้กฎแบบแก้คำผิดและหลากคำกับทุกข้อความของบอทในแชทที่เปิดอยู่ โดยแสดงให้เลือกก่อนเสมอ ใช้กับแชทเก่าที่คำติดสะสมไว้แล้ว
- **นำเข้า / ส่งออก:** เก็บรายการกฎเป็นไฟล์ JSON

### ตั้งค่า

| ตัวเลือก | ค่าเริ่มต้น | ทำอะไร |
|---|---|---|
| ถามก่อนแก้ข้อความของบอท | เปิด | ไม่ติ๊ก = แก้ทันทีโดยไม่ถาม |
| คูลดาวน์ของกฎหลากคำ | 5 | คำเดิมหรือคำในคลังที่เพิ่งใช้ จะไม่ถูกใช้อีกจนกว่าจะผ่านไปกี่ข้อความของบอท |
| ใส่กฎลงใน prompt | เปิด | ปิดแล้วจะเหลือแค่การแก้ข้อความ |
| depth | 1 | ตำแหน่งที่แทรกนับจากท้ายแชท 0 = ท้ายสุด ถ้าคำยังหลุดบ่อยให้ลด |
| role | System | role ของข้อความที่แทรก |

บรรทัด **โมเดลตอนนี้** บอกชื่อโมเดลที่ extension เห็นอยู่ และจำนวนกฎใน prompt ที่ใช้กับโมเดลนั้น ใช้เช็คได้ว่าช่องโมเดลของแต่ละกฎตรงกับชื่อจริงหรือเปล่า

## เขียนกฎใน prompt ยังไงให้ได้ผล

- **บอกสิ่งที่ให้ทำแทน** เช่น "ถ้าจะสื่อความหวง ให้แสดงผ่านการกระทำ" ได้ผลกว่าการห้ามอย่างเดียว
- **ยกคำที่ห้ามแค่ครั้งเดียว** ถ้ายกหลายครั้งหรือเป็นรายการยาว จะยิ่งกระตุ้นให้โมเดลใช้คำนั้น
- **ผูกกับโมเดลที่ติดคำนั้นจริงๆ** อย่าปล่อยช่องโมเดลว่าง ถ้าเป็นคำที่ติดอยู่โมเดลเดียว
